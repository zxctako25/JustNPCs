##  About

**JustNPCs** is a minimalistic plugin that adds ordinary NPCs to your Minecraft server.
No unnecessary features, no heavy dependencies, just NPCs that work.

Built for **Paper 1.16.5**.

##  Features

-  **Lightweight**: minimal impact on server performance
-  **Easy to use**: create and manage NPCs in a few commands
-  **Plug & play**: drop it into `plugins/` and go
-  **Simple config**: easy to read and edit
-  **No required dependencies**

##  Installation

1. Download the latest `.jar` from the [Releases](../../releases) page
2. Put it into your server's `plugins/` folder
3. Restart the server
4. Done! 🎉

##  Commands

>  Example commands, replace them with your real ones.

| Command | Description | Permission |
|---------|-------------|------------|
| `/npc create <id>` | Create an NPC at your location | `justnpcs.create` |
| `/npc remove <id>` | Remove an NPC | `justnpcs.remove` |
| `/npc list` | Show all NPCs | `justnpcs.list` |
